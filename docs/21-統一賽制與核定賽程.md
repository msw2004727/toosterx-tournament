# 全組別統一賽制（2026-10-05 主辦更新）

本次主辦要求所有組別採用提供的賽程表賽制，取代原先依組別使用不同範本的安排。
所有組別的 `requiredFormatId` 設為 `F8_GROUP_TOP_SEED_BYE`。
新建或重產必須有八支核准且未退賽的球隊，不能因名單不足自動套用其他範本。
未滿八隊先補齊名單；既有已開打的歷史賽程與結果保留。

## 對戰與排名

- 分成甲、乙兩組，各四隊打單循環，共十二場。
- 淘汰賽①：甲第二對乙第三；淘汰賽②：甲第三對乙第二。
- 淘汰賽③：甲第一對②勝方；淘汰賽④：乙第一對①勝方。
- ③④勝方打冠軍賽，敗方打季軍賽。
- ①②敗方打第五、第六名排名賽；兩組第四打第七、第八名排名賽。

每組共二十場，每隊四至六場；小組第一輪空。
排名與晉級由四個依序相依的階段解算，未完成的上游不提前指定球隊。
舊 `F8_GROUP_CROSS` 留供歷史賽程讀取，不能用於已指定新賽制的組別重產。

## 雲端套用

`node scripts/apply-schedule-plan.mjs --env=demo --input=安排.json` 預設只盤點。
加 `--apply` 會先備份到忽略版控的 `tools/backups/`，再寫入統一賽制政策。
每個安排的組別先確認沒有開打、比分、鎖定或結果，使用既有原子重產及發布流程，
保留核定分組、完整歷史稽核與版本檢查。正式環境保留既有球隊，不使用 Demo 種子資料。
