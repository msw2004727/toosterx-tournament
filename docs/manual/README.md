# 賽事系統圖文快速上手操作手冊

[下載 PDF](quickstart.pdf)

2026-10-05 編製，依上線版本 `0.20261005a` 與當日正式站設定，供工作人員、主辦及球隊相關人員快速教學使用。

- 36 頁，32 個圖解工作主題，涵蓋現行 23 項功能權限。
- 每個操作主題都有圓形身分標籤、功能入口、編號步驟、實際介面示範圖與操作提醒。
- 包含檢錄指派、甲乙組賽制、CSV 名冊、賽務記分、賽果管理、申訴、七項挑戰、抽獎及離線交接。
- 目錄可點選，另有 PDF 書籤、正式站 QR 與現場速查頁。
- 圖中球隊、玩家、生日及後四碼皆為示範資料。圖上的 DEMO 橫幅只屬示範環境，正式站不顯示。
- 線上報名目前關閉。報名、邀請及球隊管理流程均標明「重新開放時適用」。

登入後可在「我的 → 圖文快速上手手冊（PDF）」下載；公開檔案網址為 `/docs/manual/quickstart.pdf`。

更新功能、角色權限、賽制或活動規則時，應同步修訂手冊，重新渲染並逐頁檢查文字、截圖與步驟。
