# 首頁與組別識別（2026-09-29）

主辦從三款含模擬資料的本機互動預覽中選定 A「賽事焦點」。正式首頁使用原本的公開資料查詢、賽程發布門檻與隱私規則；模擬公告、比分、隊伍不進入正式資料庫或正式頁面。

## 主題循環

右上角只留一顆 44px SVG 按鈕。未設定時跟隨系統；保留既有使用者偏好。

- 系統深色：系統 → 淺色 → 深色 → 系統。
- 系統淺色：系統 → 深色 → 淺色 → 系統。
- 按下後 Toast 顯示目前模式，系統模式另外顯示實際配色。
- 系統變更、跨分頁同步、重新整理與輔助閱讀標籤持續有效。

## 固定組別色

| 組別 | 固定識別色 | Token |
|---|---|---|
| U6兒童組 | `#D95F3F` | `div-u6` |
| U8兒童組 | `#C08A22` | `div-u8` |
| U10兒童組 | `#3F8C55` | `div-u10` |

| 成人公開組 | `#245079` | `div-open` |

識別色在深淺主題保持相同。由固定色衍生淡底、可讀文字色與深色主按鈕；文字保留 AA 對比，色彩一律伴隨組別名稱。取消、錯誤、警告、即時狀態維持原本語意色。

`js/core/division-theme.js` 從 `js/engine/formats.js` 的 `colorToken` 取得固定對應，不在畫面各寫一份組別判斷；未知組別保持中性。切回全部組別會清除上次選取的色彩。

## 盤點及套用範圍

- 公開端：首頁組別磚、場次卡及射手列；賽程篩選；組別積分、賽程、球隊分頁；比分、球隊、球員頁；統計與直播牆。
- 我的：球隊及球員清單，依各自所屬組別呈現。
- 管理端：球隊清單、CSV 可用代碼及匯入預覽、球員補填彈窗、賽程組別分頁、場次管理與同分裁定。
- 賽務端：目前場次、場次清單、計分、檢錄及出場名單。
- 既有報名介面：組別介紹、建立球隊的選取狀態、球隊管理與邀請頁。報名關閉設定不變。

首頁主視覺維持飛達盃墨綠，組別色用於有明確所屬組別的內容；足球挑戰區使用無強調外框的入口列。
