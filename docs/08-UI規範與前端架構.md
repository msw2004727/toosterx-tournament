## 1. 設計語彙

FEDA CUP 的氣質：**草地、夜賽燈、社群感**。不要科技藍，也不要童趣糖果色——它要同時容納 U6 家長與成人公開組球員。

### 1.1 色彩 Token（2026-08-29 改版）

FEDA CUP 的氣質：**草地、夜賽燈、社群感**。

**骨架沿用 [msw2004727/FC](https://github.com/msw2004727/FC) 的 token 詞彙**
（`--bg-root` / `--bg-card` / `--bg-elevated` / `--text-primary` / `--text-secondary` /
`--text-muted` / `--border` / `--accent` …），色相換成飛達盃的識別綠。
這樣兩邊的元件可以互相搬，但視覺是自己的。實作見 `css/tokens.css`。

主題切換靠 `<html data-theme="light|dark">`，**不用** `prefers-color-scheme`。

| | 為什麼 |
|---|---|
| 淺色寫在裸 `:root` | JS 沒跑（掛掉、被擋、還沒下載完）時，畫面仍然是完整的淺色而不是沒有顏色 |
| 深色寫在 `:root[data-theme="dark"]` | 使用者選了淺色，就算系統是深色也不會被 media query 蓋回去 |
| CSS 裡完全沒有 `@media (prefers-color-scheme)` | 系統偏好由 JS 解析成 `data-theme`，只有一個地方決定主題 |

三態偏好（`system` / `light` / `dark`）存 `localStorage['feda_theme']`，
預設 `system`。FC 只有兩態，按過一次就永遠被釘住；這裡多一個 `system`
而且是預設值——大多數人不會去動它，跟著手機的日夜模式走才是對的行為。

首屏由 `index.html` 的 inline script 決定（必須在 CSS 之前，否則會先閃一次淺色），
之後由 `js/core/theme.js` 接手系統變化與跨分頁同步。
兩邊的 KEY 與解析規則必須一致，`tests/unit/theme.test.js` 會讀 `index.html` 對照。

**語意色成組給**：`--warn-bg / --warn-text / --warn-border`（`info` / `danger` / `ok` 同理）。
元件因此不必再寫任何深色版覆蓋——這是舊版 `components.css` 與 `staff.css` 裡
散落 `@media (prefers-color-scheme: dark)` 的替代方案。

完整值以 `css/tokens.css` 為準，不在這裡重抄一份（抄了就會不同步）。
對比度至少過 WCAG AA 4.5:1，`--text-muted` 也不例外——
FC 的 `#8892a4` 只有 3.5:1，這裡刻意再暗一階。

### 1.1b 圖示（不用 emoji）

全部 24×24、`stroke="currentColor"`、`fill="none"`，內嵌在 `js/core/icons.js`，
用 `icon(name)` / `iconText(name, text)` 取用。**功能性 UI 一律不得用 emoji**：

1. 每個平台長得都不一樣。🟨 在 Android 是圓角、iOS 是方角、Windows 有邊框，
   裁判要在陽光下一眼分辨黃紅牌，這種差異不能接受
2. 顏色寫死在字型裡。深色主題下 ⚪ 會消失在白底、🔴 在深底過亮
3. 字級一大就糊
4. 螢幕閱讀器會把 ⚽ 念成「足球」混在句子裡

場次狀態不用圖示而用 CSS 圓點 `.dot[data-status]`，顏色跟著主題走。
`tests/unit/icons.test.js` 會掃描整個前端原始碼，emoji 長回來就紅燈。

### 1.2 字型

```css
--font-sans: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", system-ui, sans-serif;
--font-num:  "Roboto Mono", "SF Mono", ui-monospace, monospace;  /* 比分與計時器 */
```

- 比分、計時器、背號一律用等寬數字（`font-variant-numeric: tabular-nums`），避免跳動
- Noto Sans TC 只載入 400 / 700 兩個字重，並用 `font-display: swap`

### 1.3 尺度

```css
--sp-1:4px; --sp-2:8px; --sp-3:12px; --sp-4:16px;
--sp-5:24px; --sp-6:32px; --sp-8:48px;

--r-sm:6px; --r-md:10px; --r-lg:16px; --r-full:999px;

--fs-xs:12px; --fs-sm:14px; --fs-md:16px; --fs-lg:20px;
--fs-xl:28px; --fs-2xl:40px; --fs-score:56px;

## 3. 版面

### 3.1 斷點

**手機優先，而且是窄機優先。**

| | 寬度 | 意義 |
|---|---|---|
| 最小驗證寬度 | **320px** | iPhone SE 一代與便宜 Android。不得破版，E2E 有一個 `chromium-320` 專案在跑 |
| 設計基準 | **360px** | 版面以這個寬度設計 |
| 內容最大寬 | 600px（`--page-max`） | 桌機置中，不拉寬——賽務端沒有人用桌機記分 |

320–359px 這一档只調 token（字級與間距各縮一階，見 `css/tokens.css` 檔尾），
不逐個元件改。唯一需要個別處理的是記分板：兩側各有 44px 的加減鈕加上兩位數比分，
一列剛好塞不下，所以窄機把加減鈕改成 40 寬 × 44 高——
高度仍滿足觸控目標，寬度讓一列進得去。

E2E 的 `noHorizontalScroll()` 會列出**是哪一個元素**溢出，
不是只說「有橫向捲軸」——後者查起來很痛苦。

### 3.2 公開端導覽

手機底部固定導覽列（5 項）：

```
[ 首頁 ]  [ 賽程 ]  [ 排名 ]  [ 挑戰 ]  [ 更多 ]
```

桌機改為頂部橫向導覽。

### 3.3 賽務端版面

- 頂部：場次資訊＋連線狀態（固定）
- 中間：內容（可捲動）
- 底部：主要動作按鈕（固定，安全區內 `env(safe-area-inset-bottom)`）
- 所有主要按鈕在螢幕下 40%（拇指可及）

## 5. 前端檔案結構

對齊 FC 的 `CLAUDE.md` 檔案責任表：

```

│   │   ├── store.js           監聽管理與 unsubscribe 回收
│   │   ├── sync.js            離線佇列狀態與 UI 三態

│   │   ├── team/              球隊與球員
│   │   ├── stats/             統計榜單
│   │   ├── stream/            YouTube 嵌入
│   │   ├── staff/             賽務台、檢錄、出場名單
│   │   ├── challenge/         挑戰區（玩家）
│   │   ├── booth/             挑戰攤位（工作人員）
│   │   └── admin/             管理後台
│   ├── lib/
│   │   ├── qr-scan.js         BarcodeDetector + jsQR fallback

│   │   └── format.js          時間、比分、成績格式化
│   └── engine/
│       ├── berger.js          循環賽程產生（與 Functions 共用邏輯）
│       ├── standing.js        積分計算（前端僅預覽用）
│       └── ranking.js         同分排序（與 Functions 共用）
├── pages/                     動態 HTML fragment
├── css/
│   ├── tokens.css             §1 的變數

| 資源 | 策略 |
|---|---|

## 7. 版本管理

```
0.YYYYMMDD{suffix}     例：0.20260928、0.20260928a
```

同步四處（由 `scripts/bump-version.js` 統一）：

1. `js/config.js#CACHE_VERSION`
2. `sw.js#CACHE_NAME`
3. `index.html` inline 版號
4. 靜態資源 query 版號

主站 JS/HTML/CSS 變更必須 bump；純文件／註解不 bump。

## 9. 內容與文案原則

- 用「場次」不用「比賽編號」；用「完賽」不用「結束」
- 錯誤訊息要說**下一步**：不是「驗證失敗」，而是「這張球員證不屬於本場次，請確認是否走錯場地」
- 時間一律 24 小時制（`09:30`），日期用 `10/9（四）`
- 兒童組不用「淘汰」字眼，用「名次賽」
- 所有面向家長的文案避免競技壓力用語
