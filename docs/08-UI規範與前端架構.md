## 1. 設計語彙

FEDA CUP 的氣質：**草地、夜賽燈、社群感**。不要科技藍，也不要童趣糖果色——它要同時容納 U6 家長與成人公開組球員。

### 1.1 色彩 Token

```css

  /* 品牌 */
  --brand-900:#0B2E20;  /* 深草綠，Header 底色 */
  --brand-700:#12513A;
  --brand-500:#1B7A56;  /* 主色 */
  --brand-300:#5FB894;
  --brand-100:#DCF2E7;

  /* 強調（賽事熱度、LIVE） */
  --accent-600:#D94F2B;  /* 磚紅，LIVE、進球 */
  --accent-400:#F2793E;
  --gold-500:#D4A03C;    /* 冠軍、獎項 */

  /* 中性 */

  --ink-300:#B9C2C7; --ink-100:#E9EDEF;

```

### 1.2 字型

```css
--font-sans: "Noto Sans TC", "PingFang TC", "Microsoft JhengHei", system-ui, sans-serif;
--font-num:  "Roboto Mono", "SF Mono", ui-monospace, monospace;  /* 比分與計時器 */
```

- 比分、計時器、背號一律用等寬數字（`font-variant-numeric: tabular-nums`），避免跳動
- Noto Sans TC 只載入 400 / 700 兩個字重，並用 `font-display: swap`

## 2. 核心元件

## 3. 版面

### 3.1 斷點

| 名稱 | 寬度 | 版面 |
|---|---|---|
| `sm` | < 480px | 單欄，底部導覽列 |
| `md` | 480–839px | 單欄加寬 |
| `lg` | 840–1199px | 雙欄（主內容＋側欄） |
| `xl` | ≥ 1200px | 三欄（後台用） |

### 3.2 公開端導覽

手機底部固定導覽列（5 項）：

```
[ 首頁 ]  [ 賽程 ]  [ 排名 ]  [ 挑戰 ]  [ 更多 ]
```

桌機改為頂部橫向導覽。

### 3.3 賽務端版面

- 頂部：場次資訊＋連線狀態（固定）
- 中間：內容（可捲動）
- 底部：主要動作按鈕（固定，安全區內 `env(safe-area-inset-bottom)`）
- 所有主要按鈕在螢幕下 40%（拇指可及）

## 4. 動效

| 場景 | 動效 | 時長 |
|---|---|---|
| 比分變動 | scale 1→1.15→1，底色閃 | 250ms |
| 新事件插入 | 由上滑入＋淡入 | 200ms |
| 頁面切換 | 淡入（不做橫向滑動，避免與瀏覽器手勢衝突） | 150ms |
| LIVE 徽章 | 脈動 opacity | 1.6s 循環 |
| 掃碼成功 | 綠色橫幅由下彈出 | 180ms |
| 骨架載入 | shimmer | 1.2s 循環 |

一律尊重 `@media (prefers-reduced-motion: reduce)`：關閉所有非必要動畫。

│   │   ├── challenge/         挑戰區（玩家）

## 6. PWA

| 項目 | 設定 |
|---|---|
| `name` | FEDA CUP 2026｜飛達盃 |
| `short_name` | FEDA CUP |
| `display` | `standalone` |
| `theme_color` | `#0B2E20` |
| `background_color` | `#0B2E20` |
| `icons` | 192／512／maskable |
| `start_url` | `/?src=pwa` |

Service Worker 快取策略（遵守 FC 的 R-REL-013：**HTML 不得 cache-first**）：

| 資源 | 策略 |
|---|---|
| HTML | Network-first，離線退回快取 |
| JS / CSS（帶版號） | Cache-first |
| 隊徽 / 球員照 | Stale-while-revalidate |
| Firestore | 由 SDK 自行處理（`persistentLocalCache`） |

賽務端可「加入主畫面」，現場開啟更快且全螢幕。

## 7. 版本管理

```
0.YYYYMMDD{suffix}     例：0.20260928、0.20260928a
```

同步四處（由 `scripts/bump-version.js` 統一）：

1. `js/config.js#CACHE_VERSION`
2. `sw.js#CACHE_NAME`
3. `index.html` inline 版號
4. 靜態資源 query 版號

主站 JS/HTML/CSS 變更必須 bump；純文件／註解不 bump。

## 9. 內容與文案原則

- 用「場次」不用「比賽編號」；用「完賽」不用「結束」
- 錯誤訊息要說**下一步**：不是「驗證失敗」，而是「這張球員證不屬於本場次，請確認是否走錯場地」
- 時間一律 24 小時制（`09:30`），日期用 `10/9（四）`
- 兒童組不用「淘汰」字眼，用「名次賽」
- 所有面向家長的文案避免競技壓力用語
