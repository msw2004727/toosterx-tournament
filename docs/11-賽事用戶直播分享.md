# 賽事用戶直播分享

每場公開賽事頁的資訊下方設置「球迷直播分享」。任何 LINE 登入者都能分享 YouTube 影片或直播連結，不需要賽務身分。觀看免登入。

## 操作與版面

1. 點「分享直播」，貼上 YouTube 網址，送出後公開 LINE 使用者名稱與 YouTube 造型的「直播」按鈕。
   尚未登入或使用 Demo 匿名模擬身分時，先完成 LINE 登入，授權後返回原賽事頁。
2. 只有一筆分享時使用整列大按鈕，最小高度 64px。2–4 筆採雙欄及 48px 按鈕；5 筆以上縮小間距，按鈕保留 44px 點擊區域，較寬畫面增加欄數。
3. 預設載入 24 筆，按「顯示更多直播」每次增加 24 筆。同一使用者可分享不同影片，同一場的同一影片只接受一次；不同使用者可分享相同影片。
4. 點直播按鈕才載入站內播放器，同時只播放一個。提供「在 YouTube 開啟」連結。比分或事件更新保留目前播放器；切換賽事／頁面時停止播放並回收監聽。
5. 分享者本人與管理員以上看得到移除入口。移除前確認，收到後端成功回應才顯示完成。離線時停止新增／移除操作；失敗可重試，同一指令沿用操作代碼。

名稱以文字呈現，長名稱在密集卡片中截短、保留完整名稱提示。公開清單不顯示原始網址、縮圖、聯絡資料或 LINE UID。

## 身分與資料

| 身分 | 觀看 | 分享 | 移除自己的分享 | 移除他人的分享 |
|---|---|---|---|---|
| 未登入 | 可以 | 不可 | 不可 | 不可 |
| LINE 一般用戶／攤位／檢錄／裁判／記錄員 | 可以 | 可以 | 可以 | 不可 |
| 啟用中的管理員／總管 | 可以 | LINE 登入時可以 | 可以 | 可以 |
| Demo 匿名身分 | 可以 | 不可 | 不可 | 只有啟用中的管理員／總管可以 |

寫入使用 `shareMatchStream` callable。後端驗證 Firebase Custom Token 登入（此系統由 `lineLogin` 簽發）、目前工作人員角色與 active 狀態、賽事存在、影片格式及私人所有權。姓名由 `users/{uid}` 取得，不接受分享指令自帶的姓名或擁有者。

| 路徑 | 內容 | 客戶端權限 |
|---|---|---|
| `events/{event}/matches/{match}/streamShares/{shareId}` | 名稱、影片 ID、時間、不可逆雜湊分享代碼 | 公開讀取；禁止直接寫入 |
| 同場次 `streamShareOwners/{shareId}` | 私人 ownerUid | 本人或管理員讀取；禁止直接寫入 |
| `users/{uid}/streamShareOperations/{operationId}` | 指令收據 | 由後端讀寫 |
| 活動 `audits/{auditId}` | 新增／移除的 before、after、執行者及時間 | 依既有管理權限讀取 |

新增／移除、私人所有權、操作收據與稽核在同一交易提交。客戶端不能直接刪除或變更擁有者，其他登入者、低階工作人員及停用管理員也無法用 API 移除他人分享。

URL 只接受 YouTube 影片網址並抽取 11 碼影片 ID，拒絕偽裝網域、憑證、特殊協定及任意 HTML。影片是否正在直播、是否允許嵌入由 YouTube 決定；無法嵌入時可用原影片連結觀看。[YouTube 官方嵌入文件](https://developers.google.com/youtube/player_parameters)

## 發布順序

先部署 Demo callable 與 Firestore 規則，再發布 Demo 前端並驗證登入、分享、觀看及移除。Demo 驗收完成後，同樣順序發布正式站。此功能不需要搬移既有賽程或用戶資料。
