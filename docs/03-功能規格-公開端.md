# 03｜功能規格：公開端（觀眾／球員／家長）

> 對象：完全免登入。設計基準 390×844（iPhone 14），桌機為加寬版面。
> 目標：**現場家長掏出手機 3 秒內看到「我的孩子那場現在幾比幾」。**

---

## 1. 頁面路由

採 Hash 路由（與 FC 一致，靜態託管不需伺服器 rewrite）。

| 路由 | 頁面 | 說明 |
|---|---|---|
| `#/` | 首頁 | 現在進行中、今日賽程、快速入口 |
| `#/schedule` | 賽程 | 依日期／組別／場地／球隊篩選 |
| `#/match/:matchId` | LIVE 比賽頁 | 即時比分、事件流、陣容、直播 |
| `#/division/:divisionId` | 組別頁 | 積分榜、賽程、晉級圖、最終排名 |
| `#/division/:divisionId/bracket` | 晉級圖 | 排名階段對戰樹 |
| `#/teams` | 球隊列表 | 依組別分群 |
| `#/team/:teamId` | 球隊頁 | 簡介、名單、賽程、戰績 |
| `#/player/:teamId/:memberId` | 球員頁 | 簡介、數據、出賽紀錄 |
| `#/stats` | 統計 | 射手榜、助攻榜、紅黃牌、球隊數據 |
| `#/live` | 直播牆 | 各場地 YouTube 並列 |
| `#/challenge` | 挑戰區 | 見 `06-Challenge挑戰系統.md` |
| `#/results` | 賽後成果 | 最終排名、獎項、照片牆 |
| `#/info` | 賽事資訊 | 規程、場地圖、交通、聯絡、贊助商 |

**深連結**：所有頁面可直接分享，且具備 Open Graph 標籤（`og:title` `og:image` `og:description`）。比賽頁的 `og:image` 由 Cloud Function 動態產生比分圖（P2）。

**狀態徽章**

| `checkin` | 檢錄中 | 琥珀 |
| `ready` | 即將開賽 | 琥珀 |

- 依 `kickoffAt` 升冪，同時間依 `venueId`
- 以「時段」分隔（每 30 分鐘一個群組標題）
- 未開賽的排名階段場次顯示 placeholder 文字（如「A組第1名 vs B組第2名」），並以斜體＋虛線框呈現
- 兒童組若啟用仁慈規則且分差 ≥ 7，比分顯示為 `7+ - 0`

### 4.2 分頁內容

| 分頁 | 內容 |
|---|---|
| **直播** | YouTube 嵌入播放器；若無直播顯示場地照或賽事主視覺 |
| **事件** | 時間軸（預設分頁，最常看） |
| **陣容** | 雙方先發／替補，以球衣號＋姓名列出；點擊進球員頁 |
| **統計** | 進球、射門（若有記錄）、黃牌、紅牌、換人數、控球（不做） |

### 4.3 即時性

```js
// 兩個監聽
onSnapshot(matchRef, renderScoreboard);
onSnapshot(query(timelineRef, orderBy('seq','desc'), limit(50)), renderTimeline);
```

- 比分變動時，記分板數字做一次 **scale 彈跳動畫**（250ms）＋ 該隊底色閃一下
- 新事件插入時由上方滑入
- 進球時（若使用者允許）觸發 `navigator.vibrate(200)`

### 4.4 比賽時鐘

前端推算，不寫入 Firestore：

```js
function displayMinute(match) {
  const { running, periodStartedAt, elapsedSecAtPause, addedTimeSec } = match.clock;
  const base = { pre:0, h1:0, ht:null, h2:HALF_SEC, et1:FULL_SEC, et2:FULL_SEC+ET_SEC }[match.period];
  if (base === null) return '中場';
  const sec = running
    ? elapsedSecAtPause + (Date.now() - periodStartedAt.toMillis())/1000
    : elapsedSecAtPause;
  const min = Math.floor((base + sec)/60) + 1;
  const half = division.matchDurationMin / 2;          // 成人組 30 分鐘 → 半場 15
  const cap = { h1: half, h2: division.matchDurationMin }[match.period];
  return min > cap ? `${cap}+${min-cap}'` : `${min}'`;
}
```

⚠️ 需處理裝置時鐘偏移：首次載入時以 Firestore 伺服器時間戳校正 `clockSkew`，之後都用 `Date.now() - clockSkew`。

### 4.5 未開賽 / 已完賽時的差異

| 狀態 | 記分板 | 直播 | 事件 |
|---|---|---|---|
| 未開賽 | 顯示開賽時間與倒數 | 顯示「直播將於開賽前 10 分鐘開始」 | 顯示「尚未開賽」 |
| 進行中 | 即時比分＋分鐘 | 播放器 | 即時 |
| 已完賽 | 最終比分＋「全場結束」 | 切為錄影回放（同一 videoId） | 完整回顧 |

## 5. YouTube 直播整合

### 5.1 三種來源

| 情境 | 設定 | 嵌入 URL |
|---|---|---|
| 單一場地固定機位、整日直播 | `venue.stream.channelId` | `https://www.youtube-nocookie.com/embed/live_stream?channel={channelId}` |
| 每場獨立影片 | `match.stream.videoId` | `https://www.youtube-nocookie.com/embed/{videoId}` |
| 賽後回放（帶時間點） | `match.stream.videoId` + `startOffsetSec` | `.../embed/{videoId}?start={sec}` |

### 5.2 實作要點

```html
<div class="video-wrap"><!-- aspect-ratio: 16/9 -->
  <iframe src="https://www.youtube-nocookie.com/embed/VIDEO_ID?rel=0&modestbranding=1&playsinline=1"
          title="FEDA CUP 直播" loading="lazy"
          allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture; web-share"
          allowfullscreen referrerpolicy="strict-origin-when-cross-origin"></iframe>
</div>
```

- 一律用 `youtube-nocookie.com`（隱私模式），減少第三方 Cookie
- `loading="lazy"` + **點擊才載入**（先顯示縮圖，避免同頁多個播放器拖慢）
- 不自動播放（行動裝置會被擋且耗流量）
- Admin 可一鍵把 `stream.status` 設為 `off`，前端改顯示佔位圖，避免直播中斷造成破圖

### 5.3 直播牆 `#/live`

各場地並列（手機直向一欄、桌機兩欄）。每格顯示：場地名、當前場次比分、播放器（點擊載入）。同一時間**最多同時播放 1 個**，點另一個時自動暫停前一個（避免行動裝置卡頓）。

## 9. 統計頁 `#/stats`

### 9.1 榜單

| 榜單 | 排序 | 同分處理 |
|---|---|---|
| 射手榜 | 進球數↓ | 出賽場次少者優先 → 並列 |
| 助攻榜 | 助攻數↓ | 同上 |
| 紅黃牌榜 | 罰分↓ | — |
| 球隊進攻 | 場均進球↓ | — |
| 球隊防守 | 場均失球↑ | — |

- 可依組別篩選（兒童組建議**預設不顯示個人射手榜**，避免比較壓力；由 Admin 用 `featureFlags.youthScorerBoard` 控制）
- 資料來源：`boards/scorers`（Function 每次 timeline 寫入後 debounce 5 秒重算）

### 9.2 射手榜計算規則

- 計入：`goal`（非烏龍）、`penalty_scored`
- 不計入：`own_goal`（記給對方球隊，但**不計入任何球員個人進球**）
- PK 大戰的罰球**不計入**個人進球（國際慣例）

## 12. 通用行為

### 12.1 關注（免登入個人化）

```js
// localStorage: feda.follows = { teams:[...], matches:[...], players:[...] }
```

- 關注球隊後，首頁「接下來」置頂該隊場次
- 賽程頁「我的關注」篩選
- P2：若使用者授權通知權限，開賽前 15 分鐘與進球時推播（Web Push）

### 12.2 分享

`navigator.share()` 優先，fallback 複製連結。分享文字範例：

```
臺中野狼 2-1 臺中猛虎｜FEDA CUP 2026 成人公開組
https://cup.toosterx.com/#/match/AO-G-A-01
```

### 12.3 空狀態與錯誤

| 情境 | 顯示 |
|---|---|
| 尚未有賽程 | 「賽程準備中，敬請期待」＋足球插圖 |
| 網路中斷 | 頂部黃色橫幅「離線中，顯示的是最後同步的資料（HH:mm）」 |
| 資料載入失敗 | 「載入失敗」＋重試按鈕，不留白畫面 |
| 查無此比賽 | 導回賽程頁並提示 |

### 12.4 效能目標

| 指標 | 目標 |

手段：App Shell 由 Service Worker 快取；隊徽用 WebP + `loading="lazy"`；字型只載入需要的字重；YouTube 播放器點擊才載入。

### 12.5 無障礙

- 比分以 `aria-live="polite"` 播報變化
- 所有色彩狀態（LIVE 紅、完賽綠）都伴隨文字或圖示，不單靠顏色
- 對比度 ≥ 4.5:1
- 觸控目標 ≥ 44×44px
- 支援深色模式（`prefers-color-scheme`）
