# 手動賽程、首頁日期及撤銷開賽

賽程管理預設為手動安排，按鈕位於左側；右側自動／逐場調整反灰、上鎖，沒有操作入口。整批發布後仍停留手動安排。

首頁依 Asia/Taipei 活動日期選擇日期頁籤。活動前選第一天，活動後保留最後一天，頁面開著跨日會重新訂閱該日場次。手動查看其他日期會維持到下一次活動日期變更。Demo 的活動測試時間也會影響首頁日期選擇；比賽時鐘仍使用真實時間。

管理員可從賽程手動卡片的「管理場次」進入「撤銷開賽」。既有賽制或參賽名單待修復時，設定提示下也保留已開打場次的管理入口。

撤銷限第一節進行中、零比分、沒有半場／PK／結果／改判／鎖定，且事件流只能包含第一節開賽事件。事件檢查由伺服器交易執行，包含已作廢事件；已有其他紀錄時使用「歸零並退回未開賽」。

撤銷保留檢錄和出場名單：雙方已確認回到 ready，單方已確認回到 checkin，未確認回到 scheduled。清除開賽時鐘及開賽事件並從首頁進行中看板移除，原賽程與對戰不變。

每次必填原因。場次、事件封存、保留名單世代、看板、稽核與冪等收據同一交易提交。resetRevision 遞增並清空 writeNonce，保留子文件同步更新 resetRevision，舊離線開賽／比分／事件／名單寫入被拒；重新載入後可重新開賽。

前端只有驗證收據的場次、動作、回復狀態、寫入世代與保留文件數後才提示成功。任何權限、過期來源、稽核提交失敗皆不產生部分變更。
