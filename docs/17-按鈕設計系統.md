# 全站按鈕設計系統

版本 `0.20260929f`，2026-09-29。

沿用飛達盃的森林綠、灰綠背景與線條 SVG，以細邊框、10px 圓角、輕微陰影和明確層級統一操作介面。

| 類型 | 設計與用途 |
|---|---|
| 主要操作 | 實心品牌綠；儲存、匯入、送出等下一步 |
| 次要操作 | 卡片底色、細邊框；下載、查看、重新載入 |
| 輕量操作 | 透明底；取消視窗、輔助導覽 |
| 重大變更確認 | 深紅實心配白字；與一般操作區別，深色主題仍有足夠文字對比 |
| 球隊狀態調整 | 分隔線操作群組，包含 SVG 圖示、操作名稱、簡短說明與箭頭；退回用琥珀色提示，取消與退費用紅色提示 |
| 分頁與篩選 | 未選取為細框；選取為淺綠底、綠色邊框與深綠文字，深色主題使用對應配色 |
| 功能入口 | 留白卡片、淺綠 SVG 圖示底座、名稱與說明 |
| 數字輸入及賽務動作 | 同一套邊框、圓角、按壓回饋；保留現場操作所需的大觸控區 |

盤點範圍：公開端、管理後台、我的與登入、球隊管理／報名、賽務台與檢錄、挑戰區及攤位；涵蓋共用按鈕、分頁、篩選、選項、功能入口、數字鍵、SVG 圖示按鈕、文件選擇及彈出視窗。

- 一般及小型按鈕皆至少 44px 高；現場主要操作保留 56px 以上。記分板 320px 下的 40 × 44px 控制保留既有規格。
- 文字採 13–16px 的主次層級，空間不足可換行，避免縮成直排。
- 滑鼠 hover、按壓、鍵盤焦點、停用狀態各自明確；尊重減少動態效果偏好。
- LINE 登入保留識別綠，改用深色文字以改善可讀性。
- 行為、資料寫入、權限及重大變更確認流程保持原有規則。

`tests/e2e/button-system.spec.js` 驗證深淺色、320／360／390／430／1280px、44px 觸控區、文字對比、鍵盤焦點，以及取消退費仍需確認且取消視窗不改資料。既有完整 E2E 同時覆蓋各功能操作。
