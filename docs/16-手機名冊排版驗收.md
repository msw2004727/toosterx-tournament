# 手機名冊與操作列排版

版本：`0.20260929e`，2026-09-29。

## 調整

- 管理後台名冊：背號、完整姓名、SVG 鉛筆按鈕在上排；生日與身分證後四碼另排，各欄完整顯示，空間不足時在欄位之間換行。缺資料明確標示「生日待補／末四碼待補」。
- 修改與補填使用同一個 44 × 44px 圖示按鈕，提供包含球員名稱的無障礙標籤、鍵盤焦點與操作說明。
- 檢錄：姓名、核對資料與操作按鈕分區；生日與後四碼的標籤和值保持同組。
- 出場名單：姓名與先發／替補操作分列；320px 仍顯示唯讀先發／替補狀態。
- 公開名冊：長暱稱可完整換行，保留隊長標示與進球數；球員所屬球隊名稱可完整換行。
- 「我的」與球隊管理：顯示完整名稱、隊名及成員名。
- 挑戰攤位：電話輸入欄與按鈕可分列，近期紀錄的長暱稱可完整換行。

## 驗收

新增 `tests/e2e/mobile-rosters.spec.js`，並在 `booth.spec.js` 增加手機排版案例。

- 320、360、390、430px 四種寬度：無橫向溢出、文字沒有截斷或與按鈕重疊。
- 管理名冊：淺色／深色、長姓名、生日缺漏、後四碼缺漏、滑鼠與鍵盤開啟編輯視窗。
- 檢錄、可編輯與唯讀出場名單、公開名冊、「我的」及挑戰攤位。
- 新增 24 項 E2E 驗收（8 案例 × 3 個瀏覽器設定，各案例再遍歷四種寬度）。
- UI 變異 `#E55`、`#E56` 防止退回擠壓名冊與文字編輯按鈕。

此次只調整資料呈現；CSV 匯入、跨隊參賽、資格判斷、權限與資料儲存規則沿用原有行為。

## 2026-09-30：E55 鑑別力補強

原 E55 注入單列 flex 後仍通過，原因是缺少姓名可用寬度和上下排位置的斷言。
fixture 增加短名、一般暱稱、四字姓名、長名與極長中英混合名；保留缺生日與末四碼。
四種寬度、雙主題與三個既有 Chromium project 都等待 document.fonts.ready：

- 姓名寬度依列內容寬度扣掉背號、44px 編輯鈕及兩個欄間距，容許 1px rounding。
- 核對資料 top 須在上排各元素最大 bottom 加 rowGap 後。
- 保留完整文字、無溢出／重疊、滑鼠與 Enter 開啟編輯的驗收。
